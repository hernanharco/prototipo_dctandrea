# prototipo_dctandrea

Landing page para doctora (Medicina Funcional & Hábitos).

## Estructura

```
├── frontend/   # Aplicación web (React + Vite + Tailwind)
└── backend/    # API (pendiente de definición)
```

## Desarrollo

```bash
cd frontend
pnpm install
pnpm dev
```
